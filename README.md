# Trot Networks Ecosystem

The Trot Networks Ecosystem is a comprehensive Minecraft plugin designed to enhance the gaming experience with a custom loading screen, audio player, character creation, and ped selector. This plugin is built using the QBox Framework, ox_lib, ox_inventory, ox_target, and qbx_medical, ensuring a seamless integration with the FiveM server environment. The plugin is optimized for performance and features a modern, dark glassmorphism UI aesthetic inspired by Perth, Western Australia.

## Install

1. Download the plugin from the GitHub repository.
2. Extract the plugin files into the `resources/[trot-networks]/` directory of your FiveM server.
3. Ensure you have the required dependencies installed: QBox Framework, ox_lib, ox_inventory, ox_target, and qbx_medical.
4. Start or restart your FiveM server to load the plugin.

## Use

1. **Loading Screen**: The custom loading screen will automatically appear when players join the server. Use the audio player to play/pause tracks, adjust the volume, and switch between tracks.
2. **Character Creation**: Access the character creation menu to customize your character's appearance and select a ped model.
3. **Ped Selector**: Use the ped selector to change your character's appearance in-game.
